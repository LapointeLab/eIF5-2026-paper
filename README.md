Public Repository for "A codon-sensitive conformational switch gates commitment to translation start sites".

The 'Code' directory contains the inhouse matlab scripts used to analyze single-molecule experiments.

The 'molecular_dynamics' directory contains files to help replicate the reported MD findings.

Directories for individual Figures contain single-molecule data and analyses for the indicated experiments, which can be matched to Supplementary Table 2. '.mat' files contain the traces and quantified data. '.sfit' contain the fits of data to exponential and gaussian functions.
